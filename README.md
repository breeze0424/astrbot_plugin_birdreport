# 鸟讯查询（astrbot_plugin_birdreport）

作者：如风。

定时向指定 QQ 群 / QQ（私聊）推送**指定城市过去 24 小时**的观鸟鸟讯，数据来自[中国观鸟记录中心](https://www.birdreport.cn/)公开报告，可由 AstrBot 主 AI 生成简短导语。

## 功能

- **定时推送**：每个订阅可配置「城市 + 时间（北京时间 HH:MM）+ 目标群号/QQ 号」，到点自动查询并发送。
- **主 AI 导语**：在配置面板选一个聊天模型后，可生成一句简短开场白；各地点的鸟种正文由程序固定生成。
- **即时查询**：`/鸟讯 <城市>` 立即查询；AI 工具 `query_bird_news` 让主 AI 在对话里也能查。
- **城市下拉**：随插件版本分发，仅地级市 / 直辖市 / 特别行政区，不含区与县级市。运行时城市缓存可单独刷新。

## 配置（WebUI → 插件 → 鸟讯查询 → 配置）

| 字段 | 说明 |
| --- | --- |
| AI 导语模型 | 选一个聊天模型（对应主 AI）。留空则直接发送分地点鸟讯。 |
| 订阅列表 | 可添加多条，每条见下表 |

每条订阅的字段：

| 字段 | 说明 |
| --- | --- |
| 城市 | 下拉选择（birdreport 支持的地级市 / 直辖市 / 特别行政区） |
| 发送时间 | `HH:MM`，北京时间 24 小时制，例如 `08:30` |
| 平台 | 目前仅 `aiocqhttp`（OneBot / QQ） |
| 目标类型 | `group`（群聊）/ `private`（私聊） |
| 目标 ID | 群聊填群号、私聊填 QQ 号 |
| AI 导语 | 开 = 主 AI 生成简短开头；关 = 只发固定格式的地点正文 |
| 启用 | 是否启用该订阅 |

## 指令

| 指令 | 说明 |
| --- | --- |
| `鸟讯 厦门` / `/鸟讯 厦门` | 立即查询厦门过去 24 小时鸟讯并发送（城市名可简写，如「厦门」「北京」） |
| `刷新城市` | 重新从 birdreport 拉取省市列表，立即用于查询和订阅；配置面板下拉随插件版本更新 |

> **如何触发指令**：AstrBot 的指令需要先「唤醒」机器人——发 `@机器人 鸟讯 厦门`，或先叫唤醒词（如你设的「米库拉斯」）再加 `鸟讯 厦门`。`/鸟讯` 也做了别名兼容，但 `/` 本身不是唤醒词，直接发 `/鸟讯` 不会唤醒机器人。
>
> 更自然的用法：直接在群里问主 AI「厦门今天有什么鸟？」或「帮我查一下厦门最近24小时的鸟讯」，主 AI 会自动调用 `query_bird_news` 工具并把结果转述成自然语言。

## AI 工具（对话中查询）

插件注册了 AI 工具 `query_bird_news`：主 AI 在对话中被问到鸟讯时，会调用它拿到按地点排列的摘要，再由主 AI 转述成自然语言回复。

正文呈现规则：每次最多展示 10 处地点，每处最多列出 5 种鸟并标明还有多少种；单条超过 700 字时按地点拆分。地点按报告编号从新到旧选取。

## 时间窗口规则

固定「往前 24 小时、按整点对齐、不含尚未结束的当前小时」：

- 发送时刻 T → 窗口终点 = `floor(T, 1小时) − 1小时`，起点 = 终点 − 24 小时。
- 例：8:00 / 8:30 / 8:59 发送的都是「前日 7:00 至 当日 7:00」；9:00 发送的是「前日 8:00 至 当日 8:00」。

## 注意事项

- **验证码**：网站有反滥用限制。本插件已做分页限速 + 每篇详情间隔，并限制单次最多展开 30 篇鸟种明细。先覆盖每个展示地点，再补读较新报告；未读报告的鸟种不纳入「另有 X 种」。若仍触发验证码，会在群里收到提示并跳过本次，不会误报为「无鸟讯」。
- **QQ 适配器**：主动发消息面向 `aiocqhttp`（OneBot）。
- **协议易变**：鸟讯接口的加密/签名若被网站更新，查询会报「协议变化」而非返回空结果，届时需按 `core/client.py` 重新核对页面脚本。
- **数据口径**：`count` 是报告篇数、`taxoncount` 是鸟种数，都不是鸟只个体数；同一鸟种跨报告的数量不做相加。
- **城市缓存**：运行时刷新的列表保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_birdreport/regions.json`。启动时优先读取此缓存；缺失或损坏时使用插件自带的 `data/regions.json`。插件更新不会覆盖运行时缓存。
